# Dragon Gaming Assets

Static game assets served by GitHub Pages for the Dragon Gaming platform.

Games live at `games/<slug>/`. Catalog entries in the main platform repository reference each game by its absolute URL:

`https://dragon-gaming-platforms.github.io/Dragon-Gaming-Assets/games/<slug>/`

This repository has no blanket license. Per-game attribution and licensing information lives in the main repository's `THIRD_PARTY.md`.
