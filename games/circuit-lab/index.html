At t = τ the capacitor is 63% charged; at 5τ it is 99%. The current starts at V₀/R and decays to zero — the capacitor blocks DC once full.

Keys 1–4 load presets, Space charges, D discharges. Try Huge: τ = 100 s, so the curves crawl. Then Fast: τ = 0.01 s, done before you blink.
