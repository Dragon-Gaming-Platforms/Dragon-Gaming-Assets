# QR Code Studio

An original local-first interface around the vendored `qrcode-generator` 1.4.4 JavaScript library by Kazuhiko Arase. The library and UTF-8 support add-on are served from `vendor/`; there are no CDN or API calls. Content is encoded in the browser, then drawn to Canvas or emitted as an SVG for download.

The wrapper and interface are MIT licensed (`LICENSE`). The vendored QR implementation and UTF-8 add-on retain their separate MIT notice (`LICENSE-QRCODE-GENERATOR.txt`). The package metadata declares MIT; the upstream source headers identify Kazuhiko Arase and link to the MIT license.
