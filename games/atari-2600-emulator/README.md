# Atari 2600 Emulator

Javatari 5.0.4's self-contained embedded browser build is served locally with its AGPL-3.0 source and license. The wrapper disables URL-parameter media loading and background keep-alives. The emulator contains no game/cartridge ROMs; users load their own local files. Online NetPlay is optional and is not needed for local play.

- Corresponding upstream source is included in `source/javatari/`.
