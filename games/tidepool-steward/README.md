# Tidepool Steward

An original, self-contained intertidal ecosystem strategy game. Restore a small coastal reserve across a twelve-week season by planting kelp and eelgrass, clearing debris, and protecting habitat. Weather, runoff, and storms influence a simplified food web.

## Run

Open `index.html` in a modern browser. All code and presentation are local; the game uses no external assets, libraries, APIs, or network services.

## Play

Select a tile on the 8 × 5 map, then choose one of the available stewardship actions. You have two actions per week. Advance the season to resolve temperature, water clarity, habitat, and species changes. Finish with a biodiversity index of 64 or higher and every species group at 28 or higher to meet the reserve goal. Restart to try a different action plan.

Species values are simplified game indices, not scientific population estimates or ecological advice.
