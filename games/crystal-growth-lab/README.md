# Crystal Growth Lab

Diffusion-limited aggregation: random walkers freeze on contact and grow branching fractal crystals.

## Features

- Self-contained Canvas 2D simulation with live parameters and presets
- Keyboard shortcuts and pointer interaction
- No third-party assets, libraries, or network requests

## Controls

- Sliders for stickiness, walkers and speed; seed shape and palette selectors

## Implementation

Dependency-free HTML, CSS, and JavaScript. Everything needed to run lives in this folder.
