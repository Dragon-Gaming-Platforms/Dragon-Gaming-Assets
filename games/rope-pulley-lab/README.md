# Rope Pulley Lab

A physics contraption toy with Verlet integration rope simulation and anchor dragging.

## Features

- Interactive canvas: drag anchor point
- Rope physics with Verlet integration
- Controls: pause/resume, reset, clear
- No external dependencies or network requests

## Controls

- **Mouse / Touch**: drag anchor point
- **Space**: pause / resume
- **C**: clear rope

## Implementation

Self-contained HTML + JavaScript + Canvas 2D. Verlet integration applied per tick.
