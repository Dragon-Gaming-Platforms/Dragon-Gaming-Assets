# Graph Theory Lab

An original graph-search visualizer with a sample weighted, undirected network. Step through BFS, DFS, and Dijkstra searches, compare their frontiers, and inspect a resulting path and cost.

## Run

Open `index.html` in a modern browser. The editor, algorithms, and canvas are local; no external libraries, assets, or network services are used.

## Controls

Select the algorithm, start, and goal. Run a search, then step or play the expansion trace. Drag nodes to rearrange them; click empty canvas to add a node. Enable Edit connections to toggle an edge between two clicked nodes; right-click removes a node.
