# Mega Drive / Genesis Emulator

This is the upstream mdcore 0.1.0 web player, hosted locally with its JavaScript, WebAssembly core, and audio worklet. No games or commercial ROMs are included. Pick a ROM from your device; the player reads it in this tab and does not upload it.

The core is explicitly experimental: its authors report testing Sonic the Hedgehog 1 and 2 only, and list several hardware gaps. See `UPSTREAM-README.md` and the upstream project for details.
