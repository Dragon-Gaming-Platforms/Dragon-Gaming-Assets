# Mirror Lab

A spherical mirror focuses light at its focal point. The mirror equation 1/f = 1/dₒ + 1/dᵢ predicts where the image forms — real and inverted, or virtual and upright.

## Features

- Spherical mirror ray diagram with the three principal rays
- Plane (f = ∞), concave (f > 0) and convex (f < 0) mirrors
- Mirror equation, magnification m = −dᵢ/dₒ, image type and orientation readouts
- Draggable object tip; virtual images drawn dashed behind the mirror

## Controls

Focal-length, object-distance and object-height sliders, three presets (concave/convex/plane), rays toggle, draggable object tip; keys 1–3 load presets

## Implementation

1/f = 1/dₒ + 1/dᵢ with f > 0 concave, f < 0 convex, f = ∞ plane (dᵢ = −dₒ). The harness verifies the plane mirror gives dᵢ = −dₒ and m = +1, a concave mirror with dₒ = 250, f = 100 gives dᵢ = 166.7 and m = −0.667, an object inside f gives a virtual magnified image, a convex mirror always gives a virtual reduced image, and the 1/f identity holds.
