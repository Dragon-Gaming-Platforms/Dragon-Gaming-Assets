48K profile · local firmware

ZX Spectrum Emulator

A browser-hosted 48K machine powered by JSSpeccy and the freely licensed Open82 replacement firmware.

OPEN82 · GPL
Local files only. No commercial games or original Sinclair ROMs are bundled. Use the emulator's File menu to open a 48K snapshot or tape image you are entitled to use.

Load a program

Choose File → Open in the emulator for .SNA, .Z80, .SZX, .TAP or .TZX. For a tape, enter LOAD "" in BASIC and start the tape from the toolbar. Use 48K-compatible files.

Firmware and compatibility

Open82 is an independent, GPL-licensed replacement for the 48K system ROM. It is not the original Sinclair firmware, so software that relies on undocumented ROM behavior may not work.
