# Fluid Ink Lab

A fluid diffusion simulation where ink drops spread and fade over time.

## Features

- Interactive canvas: drag to paint ink drops
- Diffusion and fading simulation
- Controls: pause/resume, clear
- No external dependencies or network requests

## Controls

- **Mouse / Touch**: drag to paint
- **Space**: pause / resume
- **C**: clear drops

## Implementation

Self-contained HTML + JavaScript + Canvas 2D. Diffusion applied per tick.
