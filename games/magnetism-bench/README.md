# Magnetism Bench

An original, self-contained visual experiment for exploring magnetic-field directions around bar magnets. The field is computed from a simplified pair-of-poles model; this is qualitative visualization, not engineering data.

## Run

Open `index.html` in a modern browser. It uses only local JavaScript and Canvas; no external assets, libraries, sensors, or network services are required.

## Controls

Choose a single, attracting, or repelling arrangement. Drag a magnet to move it, click empty canvas to add one, rotate the selected magnet by 45 degrees, or remove it. Move the cursor to read the local probe field and direction.
