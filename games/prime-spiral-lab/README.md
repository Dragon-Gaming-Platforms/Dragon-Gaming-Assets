# Prime Spiral Lab

An original number-theory visualization. Consecutive integers walk outward on a square Ulam spiral; a sieve highlights primes and makes diagonal structures easy to explore.

## Run

Open `index.html` in a modern browser. The spiral, sieve, and drawing are local; there are no external datasets, libraries, or network services.

## Controls

Adjust the maximum integer (100–6,000), cell scale, and color mode. Prime density and the exact number of primes in the plotted range update with the diagram.
