# Erosion Lab

An original, self-contained terrain experiment. Sculpt a procedural height field, add rainfall, and watch water route downhill while carrying and depositing sediment.

## Run

Open `index.html` in a modern browser. Simulation, drawing, and presets are local; no external assets, libraries, maps, APIs, or network services are used.

## Controls

Drag to raise terrain; hold Shift or choose **Carve channel** in Brush mode to lower it (the mode selector also works on touchscreens). Adjust rainfall, erodibility, and brush radius. Run, step one rainfall cycle, or reset to one of three deterministic terrain presets.

This is a qualitative visual model, not geographic data or a predictive erosion tool.
