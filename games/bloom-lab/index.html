A Bloom filter trades certainty for space: a bit array plus k hash functions remembers membership with no false negatives — but other items' bits can fake a yes.

A Bloom filter never says no to a member — but bits set by other items can make a stranger look like a member. That false-positive rate is (1 − e^(−kn/m))^k.
