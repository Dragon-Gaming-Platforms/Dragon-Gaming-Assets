Suguru

A region of size k must contain each digit from 1 to k exactly once. Cells sharing an edge OR a corner must have different digits, including cells in different regions. Printed clues cannot be changed. Select a cell, then use the on-screen number pad or number keys.

Controls

Select cell then number pad / keyboard; H hint, Z undo; English help link below game.

  • The original game interface is in Simplified Chinese. Choose one of the five difficulty buttons to begin (left-to-right / top-to-bottom: easiest to hardest). The first tier is recommended for learning.
  • 提示 / H: hint. 撤销 / Z: undo. 暂停 / P: pause. 继续: resume a saved game. 菜单: return to menu. 清空存档: erase this game’s local records (confirmation required).
  • Progress is stored locally in this browser. Reload, then choose 继续 to resume. Saves are not accounts and do not transfer between browsers.
