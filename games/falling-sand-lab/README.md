# Falling Sand Lab

A cellular-automata physics sandbox where materials like sand, water, lava, fire and plants interact in real-time.

## Features

- Interactive canvas: draw and erase materials with mouse or touch
- Materials: sand, water, oil, acid, lava, fire, smoke, steam, plant, wood, stone, gunpowder, ice, eraser
- Presets: garden, volcano, waterfall, blank
- Controls: brush size slider, pause/resume, rain toggle, snapshot, clear
- No external dependencies or network requests

## Controls

- **Mouse / Touch**: draw material (left) or erase (right)
- **Space**: pause / resume
- **R**: toggle rain
- **C**: clear canvas
- **1–9, 0**: select material (keyboard shortcuts)
- **[ ]**: brush size

## Implementation

Self-contained HTML + JavaScript + Canvas 2D. Cellular-automata rules applied per tick.
