# Reaction Field

An original, self-contained reaction-diffusion visual experiment. Seed abstract reagent B into a 180 × 128 grid, adjust the feed and kill rates, and explore several Gray–Scott pattern regimes with local canvas rendering.

## Run

Open `index.html` in a modern browser. There are no external libraries, assets, services, or network requests.

## Controls

- Click or drag to seed reagent B; hold Shift while dragging to restore a patch to reagent A.
- Use Run/Pause or Space, Step once, Reset pattern, preset recipes, feed/kill sliders, speed, and color-map controls.

The model is a qualitative visual toy, not a biological or chemical prediction.
