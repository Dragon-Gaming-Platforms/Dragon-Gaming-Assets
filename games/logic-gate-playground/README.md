# Logic Gate Playground

An original, self-contained Boolean circuit workbench. Configure four sequential gates, toggle three live inputs, choose an output tap, and inspect all eight rows against a target function.

## Run

Open `index.html` in a modern browser. No external libraries, assets, APIs, or network services are used. Nothing is saved or transmitted.

## Controls

Toggle A/B/C, change each gate's two sources and operation, select the output tap, and choose a target truth table. Available operators are AND, OR, XOR, NAND, NOR, and XNOR.
