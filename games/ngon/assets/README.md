# n-gon local placeholder assets (original)

These files replace hotlinked third-party images/audio that were removed for
offline/licensing reasons. They are original placeholders (gradients/shapes and
silence), not copies of the upstream files.

- `hotpot.png` — dark gradient background placeholder
- `omega.png` — teal ring placeholder
- `hotpot-removed.png` — amber square placeholder
- `silent.wav` — 1s silence used for ambient audio slots (thunder/rain/buzz)

Upstream hotlinks (Whyisthisnotavalable/image-yy, des-boot/n-gon-downpour-sound-effects)
were unlicensed and are not vendored. See THIRD_PARTY.md.
