# Particle Life Lab

An interactive particle chemistry toy where particles attract or repel based on type.

## Features

- Interactive canvas: click to attract or spawn particles
- Attraction/repulsion matrix based on particle type
- Controls: pause/resume, spawn, clear
- No external dependencies or network requests

## Controls

- **Mouse click**: attract particles or spawn new ones
- **Space**: pause / resume
- **C**: clear particles

## Implementation

Self-contained HTML + JavaScript + Canvas 2D. Simplified attraction/repulsion applied per tick.
