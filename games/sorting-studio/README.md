# Sorting Studio

An original visualizer for bubble, selection, and insertion sort. It uses one list for all three algorithms and steps through individual comparisons, swaps, and pass boundaries while counting operations.

## Run

Open `index.html` in a modern browser. Sorting and drawing are local; no external libraries, assets, or network services are used.

## Controls

Choose an algorithm and array size, then shuffle for a new list. Press Play to animate, Step to advance one operation, or Reset list to restore the current generated values. Adjust playback speed while the animation runs.
