Diagonal Junctions

Slant-inspired · count-only variant

A diagonal in every cell. The right number of ends at every clue.

Draw ╱ or ╲ in each cell. A numbered junction counts the lines ending there; unnumbered junctions are unrestricted. This is a count-only Slant variant: closed loops are allowed.

    Four counting rules

    1. Zero: no neighboring diagonal may end at this junction.
    2. All: if the clue equals the number of adjacent cells, every diagonal must end here.
    3. Still needed: if all remaining cells are needed, their lines must end here.
    4. Already enough: once a clue is met, other neighboring lines must point away.

    These are local counting deductions. Every diagonal placed by a deduction is shared by every solution.
