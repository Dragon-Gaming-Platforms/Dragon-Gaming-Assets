Rules

Draw one diagonal, either ╱ or ╲, in every cell. A number at a junction specifies exactly how many adjacent diagonals must end there. Unnumbered junctions impose no constraint. This is a count-only Slant variant, not classic Gokigen Naname: closed loops are allowed. Generated boards are designed to be solved by local counting deductions.

Controls and progress

Pick one of five difficulty tiers (5×5 through 10×10). Select ╱ or ╲, then tap to draw that diagonal; tap a matching diagonal to erase it. Drag to draw a stroke. Starting a drag on a matching line erases that stroke. H gives one counting hint, Z undoes, X changes direction, / and backslash select directions. P or Space pauses, R restarts the same puzzle, M mutes, F requests fullscreen where available, and ? opens help. Difficulty menu returns to tier selection. The menu Resume button restores the unfinished board, time, moves and hints; settings and best records also use optional local storage. Records prioritize fewer hints, then fewer moves, then time. Clear local records affects only this game.

All runtime assets are local and no account or server API is needed. Optional browser storage may be unavailable in private browsing or restricted iframes; the games remain playable without it.
