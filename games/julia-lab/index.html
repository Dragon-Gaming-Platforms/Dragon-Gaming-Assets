c = −0.123 + 0.745i gives the Rabbit: a connected Julia set with a main body and two ears. If c is outside the Mandelbrot set, the Julia set shatters into a Cantor dust.

Drag the c sliders to morph the set. Keys 1–4 load presets, R resets. Try c = −1 + 0i (Dendrite): a tree of arcs with no interior at all.
