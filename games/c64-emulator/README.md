# Commodore 64 Emulator

A standalone HTML build of John Werner Enoksen's plain-JavaScript C64 emulator. The upstream HTML was retained as the source and entry point; external Google Fonts requests were removed, with system fonts used instead.

No BASIC, KERNAL, character-generator or 1541 ROMs and no game/disk images are bundled. The page explains the ROM requirements and stores supplied firmware only in the current browser. Load only files you are entitled to use.
