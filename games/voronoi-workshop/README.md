# Voronoi Workshop

An original, dependency-free computational geometry experiment. The canvas is partitioned so each cell contains the pixels nearest to one site. Drag, add, and remove sites to reshape the regions.

## Run

Open `index.html` in a modern browser. All cell assignment and drawing run locally; there are no external assets, libraries, maps, or network services.

## Controls

Drag a marker to move its site. Click an empty spot to add a site, or right-click a marker to remove it. Choose a scattered, clustered, or loose-grid layout; adjust site count, palette, and boundary emphasis.
