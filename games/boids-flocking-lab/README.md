# Boids Flocking Lab

An interactive flocking simulation where autonomous agents (boids) follow separation, alignment, and cohesion rules.

## Features

- Interactive canvas: click to attract or spawn boids
- Emergent flocking behavior
- Controls: pause/resume, spawn, clear
- No external dependencies or network requests

## Controls

- **Mouse click**: attract boids or spawn new ones
- **Space**: pause / resume
- **C**: clear boids

## Implementation

Self-contained HTML + JavaScript + Canvas 2D. Simplified steering behaviors applied per tick.
