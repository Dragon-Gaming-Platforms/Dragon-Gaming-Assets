    Lasting consequences.

    1. The board is 6×6. Order moves first, then Chaos; the roles do not swap. Neither player owns X or O.
    2. On every turn, either player chooses X OR O and places it on any empty cell. Use the symbol buttons above the board. Marks never move or disappear.
    3. Order wins immediately when there are FIVE OR MORE consecutive identical marks horizontally, vertically or diagonally. It does not matter which player completed the line. Six in a row counts in this edition.
    4. Chaos wins if the board becomes full without any such line. Line detection takes priority on the final placement. There are no draws or passes.
