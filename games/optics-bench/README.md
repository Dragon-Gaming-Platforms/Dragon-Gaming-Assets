# Optics Bench

An original local geometric-optics workbench for thin lenses. Compare principal rays and real/virtual images as you change object position, focal length, height, and lens sign.

Open `index.html` in a modern browser. No external assets, libraries, APIs, or network services are used.

Model uses `1/f = 1/do + 1/di` and `m = -di/do`; it is a schematic thin-lens model, not a wave-optics solver.
