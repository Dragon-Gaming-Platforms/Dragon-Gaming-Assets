# Mandelbrot Explorer

An original, dependency-free browser tool for exploring the Mandelbrot and Julia sets. The fractal is calculated in a local Web Worker and drawn to Canvas; no external scripts, assets, APIs, accounts or uploads are used.

Features include Mandelbrot landmarks, Julia-set controls, adjustable iteration detail and palettes, cursor-anchored zoom, drag-to-pan, keyboard controls, back/reset actions, and shareable URLs that encode view parameters only.
