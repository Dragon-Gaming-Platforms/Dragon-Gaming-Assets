# L-System Garden

An original, self-contained procedural drawing experiment. Five L-system grammars grow a fern, branching tree, Koch island edge, Sierpinski triangle, or dragon curve. Adjust iterations, turn angle, stroke weight, and palette.

## Run

Open `index.html` in a modern browser. All rewriting and canvas drawing happen locally; no external assets, libraries, APIs, or network services are used.
