# Hyperbolic Tiling Lab

Regular {p, q} tilings of the hyperbolic plane, spun inside a Poincaré disc.

## Features

- Five tilings: {4,5}, {5,4}, {6,4}, {3,7} and {5,5}, each verified against the angle condition
- Tiles generated by reflecting geodesic polygons across their own sides with Möbius isometries
- Geodesic edges drawn as true orthogonal circular arcs, not straight lines
- Cached tiling layer so spin, zoom and palette changes stay smooth

## Controls

- Tiling family, depth, spin and zoom sliders; palette, edge and fade toggles; drag to rotate, scroll to zoom; Space pauses the spin, R resets the view

## Implementation

A regular p-gon is built at radius tanh(r/2) with cosh r = cot(pi/p) cot(pi/q), then reflected through circles orthogonal to the unit disc. Edges are sampled as arcs and the whole tiling is cached to an offscreen canvas and blitted with a rotation transform.
