Rules and controls

Numbered circles and empty circles stay white. Each numbered circle counts the total number of black cells in all orthogonally touching black components. Count an entire component, not only its neighboring cells, and count the same component only once if it touches the circle on multiple sides. Empty circles impose no count. There is no global black connectivity or no-2×2 rule.

Tap ordinary cells to cycle unknown → black → white. Circles are fixed. Use B for black, W for white, 0/Backspace to clear, arrows to move and Enter/Space to cycle. H hints, Z undoes, N creates a new board. Mark all ordinary cells to finish. Four board sizes (6×6 through 9×9) are available. Resume and same-tier records prefer fewer hints, then moves, then time.

Interface and saves

This guide is not a full translation. Menus, diagnostics and hint prose remain partly Simplified Chinese. Browser storage is optional and game-scoped; progress cannot persist if storage is blocked or full. Fullscreen is optional and may be unavailable in an iframe.
