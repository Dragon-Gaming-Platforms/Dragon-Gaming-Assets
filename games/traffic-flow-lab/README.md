# Traffic Flow Lab

A single-lane Nagel–Schreckenberg ring road where jams appear on their own.

## Features

- Self-contained canvas simulation with live parameter controls and presets
- Keyboard shortcuts and pointer interaction
- No third-party assets, libraries, or network requests

## Controls

- Mouse / slider controls; Space to pause; S to step; R to reseed

## Implementation

Dependency-free HTML, CSS, and Canvas 2D. Everything needed to run lives in this folder.
