Insert in sorted order and a plain BST degenerates into a linked list — height n, search O(n). The AVL tree rotates to stay balanced: height stays under 1.44·log₂(n).

Keys 1–3 load presets, I inserts, D deletes, S searches, C clears. Try Sorted: watch the rotations keep the height at 4 while a plain BST would hit 30.
