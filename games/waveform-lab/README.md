# Waveform Lab

An original, dependency-free sound-design instrument for creating single tones in the browser. It is intentionally different from a song editor or tracker: there is no pattern grid or arrangement. Choose an oscillator, tune its frequency, shape the ADSR envelope, add a low-pass filter, play notes from the on-screen or computer keyboard, and export a short mono WAV.

Real-time audio uses the Web Audio API after a user gesture. WAV samples are synthesized locally in JavaScript; no audio or settings are sent anywhere.
