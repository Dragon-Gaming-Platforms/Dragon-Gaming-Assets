# ASCII Art Studio

An original, dependency-free browser tool that converts an image selected from your device into monochrome text art. Processing uses a local Canvas; images are never uploaded. Adjust width, brightness, contrast, inversion and character ramp, then copy or download the `.txt` result. A simple sample landscape is drawn in code so the tool can be tried without selecting a file.
