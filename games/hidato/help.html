Rules and controls

Fill the grid with each number from 1 to the number of cells exactly once. Consecutive numbers must share an edge or corner (diagonal moves are allowed). Printed numbers cannot be changed. Select a cell, then select a number on the pad. Arrow keys move the cursor; + or = advances the number tool, - steps back; Backspace clears the selected entry. Use the on-screen 提示 (Hint), 撤销 (Undo), and 判定 (Check) buttons; R restarts the same puzzle. The size selector (档位) offers 5×5, 6×6 and 7×7. Enter a seed in 盘号 and use 换一局 to reproduce a puzzle. New games may take a moment to generate.

Interface and saves

The original interface is Simplified Chinese. This English guide is an adaptation, not a full translation. Progress is saved locally in this browser when storage is available. Clearing this game's save does not clear other games. Fullscreen may be unavailable in an embedded player; the game does not require it.
