# Pendulum Studio

An original, self-contained damped-pendulum experiment. Adjust release angle, length, gravity, and damping, drag the bob to set its angle, and observe its motion and energy trace.

## Run

Open `index.html` in a modern browser. The simulation uses local canvas drawing and no external assets, libraries, APIs, or network services.

## Controls

Drag the bob to set an angle. Use the sliders to change the model, then Start, Step, or Reset. The equation is a simple point-mass pendulum with linear angular damping; the readout is energy per unit mass.
