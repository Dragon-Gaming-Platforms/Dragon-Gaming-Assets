Rules

Find every valid three-card set on a fixed 3×4 board. Each card has a number (1–3), shape (square/triangle/circle), color (red/blue/green) and fill (empty/solid/hatched). For each of those four attributes, the three selected cards must be all identical or all different. Two alike and one different is not allowed. Cards stay on the board and may belong to several sets.

Controls and progress

Tap any three cards to submit a set. The found counter and small card groups record discoveries; selecting the same set again does not count twice. Find every set to stop the timer and win. New Game generates a board with at least four sets. Hint flashes one unfound set; Ctrl+Shift+H also works. Copy Game ID copies the board code where browser clipboard policy permits. Enter Game ID replays a valid 48-digit ternary code containing 12 distinct cards; invalid codes are rejected. This is a fixed-board matching game, not a draw-pile edition. Reload does not preserve progress.

All runtime assets are local and no account or server API is needed. Optional browser storage may be unavailable in private browsing or restricted iframes; the games remain playable without it.
