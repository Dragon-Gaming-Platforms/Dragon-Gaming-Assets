# Interference Studio

An original, self-contained wave-superposition visual experiment. Point emitters send circular waves across a 200 × 140 canvas field; their signed amplitudes combine to reveal moving crests, troughs, and cancellation nodes.

## Run

Open `index.html` in a modern browser. The simulation and canvas rendering are local and use no external assets, libraries, APIs, or network services.

## Controls

- Click empty canvas to add an emitter (up to eight); drag a marker to move it.
- Shift-click a marker to remove it.
- Run/Pause or Space; Step phase works while paused.
- Presets set source arrangements. Wavelength, alternate-source phase, speed, and color map are adjustable.

This is a qualitative wave-interference visualizer, not a fluid or acoustics solver.
